# Minesweeper Idle — openbaar privacybeleid

Dit is de **statische, tweetalige privacywebsite** voor de Android-game
**Minesweeper Idle** van David van der Wulp.

**Publieke URL:** https://davidvdw02.github.io/puzzle-idle-privacy/

- **Standaardtaal:** Engels.
- **Taalwissel:** EN / NL met toegankelijke schuifschakelaar bovenaan.
- **Directe Nederlandse link:** https://davidvdw02.github.io/puzzle-idle-privacy/?lang=nl
- **Contact:** puzzleidlegame@gmail.com (bestaande openbare supportmail).
- **Bestanden:** `index.html` en `styles.css`; er is geen tracking,
  cookieopslag, Google Analytics of extern script aan de website toegevoegd.
- **Hosting:** GitHub Pages vanaf `main` / `(root)` van deze publieke repo.

## Publiceren

De website is een GitHub Pages-site, niet de privé Godot-game-repository.

1. Controleer op GitHub onder **Settings → Pages** of **Deploy from a branch,
   main / (root)** ingesteld is.
2. Publiceer gewijzigde bestanden op `main`. GitHub Pages maakt de website
   automatisch beschikbaar; er is **geen zelfgemaakte GitHub Actions-workflow
   of game-playtest** nodig.
3. Open de publieke URL in een privévenster. Controleer de Engelse standaard,
   de NL-schuifschakelaar en de directe `?lang=nl` link.
4. Gebruik **exact** de publieke URL in:
   - Google AdMob → Privacy & messaging → European regulations;
   - Google Play Console → App content → Privacy policy;
   - een duidelijk bereikbare privacybeleid-link **binnen de Android-app**
     (deze ontbreekt nog en moet in de spelcode toegevoegd worden).
5. Controleer de contactmail: de naam en het adres zijn overgenomen uit de
   oorspronkelijke website en niet onafhankelijk gevalideerd.

## Belangrijke inhoudelijke controle

Lees [CONTENT_AUDIT_NL.md](CONTENT_AUDIT_NL.md) voor de vergelijking met
de actuele Godot-code, de bewust gecorrigeerde fouten en de nog openstaande
releaseverplichtingen. **De privacytekst is niet automatisch juridisch
goedgekeurd.** Wanneer AdMob-liveadvertenties worden aangezet of een andere
analytics-/betalingssdk wordt toegevoegd, moet de pagina opnieuw worden
bijgewerkt en afgestemd met de Google Play Data safety-verklaring.

De privacywebsite laat bezoekers niet inloggen en vraagt geen persoonlijke
gegevens via formulieren. Een verzoek aan de ontwikkelaar kan rechtstreeks
naar het openbare supportadres worden gemaild.
